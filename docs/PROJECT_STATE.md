=== 1. PROYEK ===
Nama: Gymnasium Smart Reminder & Follow-up. Capstone Dicoding Bootcamp, ID tim DB15-I038, dikerjakan INDIVIDU oleh Eugenia Huwaida Imtinan (jalur Gen AI). Gymnasium = gym dan private coaching (target ibu-ibu, lansia, segmen menengah ke atas). Masalah: reminder kelas dan follow-up customer dilakukan manual lewat WhatsApp tanpa panduan prioritas. Solusi: aplikasi web ADMIN untuk mengelola customer, jadwal, reminder, dan status follow-up; model ML yang dilatih sendiri memprioritaskan follow-up (Low/Medium/High); Generative AI (Gemini) menyusun draft pesan sesuai prioritas dan persona; admin mengedit lalu mengirim SENDIRI lewat WhatsApp dan memperbarui status manual.
Research question: apakah model ML lebih baik dari baseline sederhana, dan bagaimana GenAI mengubah hasil klasifikasi menjadi draft yang siap pakai admin.
Alur end-to-end: reminder dibuat (Scheduled) -> admin melihat daftar reminder hari ini beserta prioritas -> klik Generate Draft -> edit pesan -> kirim manual via WhatsApp -> ubah status Sent -> lalu Responded atau No Response -> riwayat tersimpan.

FASE 4 - Generative AI (Gemini lewat backend)
Ganti placeholder POST /generate-draft. Struktur: src/api/services/{prompt_builder.py, gemini_client.py, draft_service.py, templates.py}; router di routers/drafts.py; schema respons DraftResponse {reminder_id, draft_message, draft_source ("gemini"|"template_fallback"), cached, message_type, warning (opsional)}.
Perilaku: reminder tidak ada -> 404; status bukan Scheduled -> 409 (kode draft_not_allowed). Jika draft_message sudah ada dan regenerate=false -> kembalikan yang tersimpan (cached=true, tanpa memanggil API). Selain itu bangun prompt dari data (nama panggilan, persona, prioritas, nama kelas, tanggal dan jam, pelatih, message_type, tanggal pesan terakhir bila ada), panggil Gemini, validasi (post-check), simpan ke reminders.draft_message dan draft_source, JANGAN menyentuh final_message.
